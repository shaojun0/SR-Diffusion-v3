# SR-Diffusion v3 — v2 分块掩码（block mask）训练 + 推理报告

> 日期: 2026-09-01 ｜ 分支: `main` ｜ 服务器: 2× RTX PRO 6000 (97GB)
> 本文档记录用户新提交（951c80e mask机制变更 + 415f432 bug-fix）的 v2 训练与推理测试：解码器从 KV 因果前缀掩码改为**分块掩码**，集成从 mean 改为**累加**，采样计划改 `square_block_starts` 并支持 `slice_start/slice_end` 分块切片。

---

## 1. 训练配置

| 项 | 值 |
|---|---|
| 架构 | DINOv2-large(不冻结, dim=1024) → OutputQueryDecoder(nn.TransformerDecoder 2 层, **分块掩码**) → PixelHead（无 ReEncoder, register 式） |
| 分块掩码 | 每采样步 t 只 attend 自己所在的 z_s 块（块号 ⌊√t⌋, 块 k=[k², min((k+1)²-1, N)]）；**第一个步可见自己块之前所有元素（含位置 0 = z_cls）**（415f432 bug-fix 补充） |
| 集成方式 | **累加**: F_hat = Σ_t Y_t（第 n 步结果 = 前 n 步预测之和）；loss = mean_n L1(cumsum_n Y, target) |
| 采样切片 | `slice_start=4 / slice_end=9` → square_block_starts(576)[4:9] = **[25, 36, 49, 64, 81]**（5 步） |
| 数据 | construction_site 工地: 7009 训练 + 3004 测试（1600×900 画布 → 448×252, 576 patches） |
| 口径 | fp32 全精度、平权 mean、bs16/卡×2、lr=1.5e-4 cosine、40 epochs / **8760 步** |
| 产物 | `output/phase1_v2_block/final_model.pt`（1.36GB fp32, 含 DINO 权重） |

## 2. 训练结果

eval 曲线（每 2000 步, 归一化空间）:

| step/epoch | 2000 (9.1) | 4000 (18.3) | 6000 (27.4) | 8000 (36.5) | 8760 (40, final) |
|---|---|---|---|---|---|
| eval_loss | 0.4783 | 0.4199 | 0.3436 | 0.3059 | **0.3045** |

- 最终 eval_loss = **0.3045**（单调收敛; 优于上版 v2 new 的 0.349）
- 训练时长: **~2.95 h**（train_runtime = 1.063e4 s, 0.82 it/s）

## 3. 推理测试（全量 3004 张 test, 0-255 像素空间）

### 3.1 全量重建

| 指标 | 数值 |
|---|---|
| 全量重建像素 L1 (0-255) | **17.46 ± 6.16** |
| 全量重建像素 L1 (归一化) | 0.3054（与最终 eval_loss 0.3045 一致） |
| 推理耗时 | 158 s |

### 3.2 渐进曲线（5 步累积, 0-255 像素 L1）

```
步  1 (块起点  25, 前  1 步累积) L1 = 17.42
步  2 (块起点  36, 前  2 步累积) L1 = 17.41
步  3 (块起点  49, 前  3 步累积) L1 = 17.42
步  4 (块起点  64, 前  4 步累积) L1 = 17.44
步  5 (块起点  81, 前  5 步累积) L1 = 17.46
```

5 步近乎持平（17.41–17.46）：分块掩码下第一步已可见前段全部信息（含 z_cls），累加集成对重建质量的边际贡献很小——中段分块信息已足够。

### 3.3 与历史版本对比（全量重建 L1, 0-255）

| 版本 | 全量 L1 | 说明 |
|---|---|---|
| 旧 v2（2026-08-27, KV 因果, 无 register） | 23.41 | 像素目标首版 |
| v2 register K=128 | 28.02 | register + K=128 |
| v2 边界 K=64（decoder_steps=[32,64]） | 22.03 | 压缩边界实验 |
| v2 新版本 standard（register, 切片 4/9） | 19.99 | 2026-08-31 报告 |
| **v2 分块掩码（本报告, register + block mask + 切片 4/9）** | **17.46** | **历史最佳** |

## 4. 分析与结论

1. **分块掩码 + 累加集成显著提升**: 全量重建 L1 17.46, 较上版 standard（19.99）再降 ~13%, 较旧 v2（23.41）降 ~25%——当前 v2 系列最佳配置。
2. **训练收敛更好**: eval_loss 0.4783 → 0.3045, 最终值低于上版（0.349）; 推理归一化 L1（0.3054）与训练 eval_loss 完全一致, 无口径偏差。
3. **渐进曲线近乎全平**: 分块掩码下每个采样步负责自己的 z_s 块, 第一步可见前段全部信息, 累加集成时各步预测互补, 重建质量随步数几乎不变——"信息在第一步即充分"。
4. **切片语义生效**: `[4:9]` 在新分块计划上取中段 5 块 [25,36,49,64,81]（与旧平方计划切片取值不同但语义对齐: 跳过最粗的最前块）; bug-fix 后第一个步可见前段信息（含 z_cls）, 避免切片丢信息。
5. **后续建议**: 渐进曲线全平说明分块信息在第一步已充分, 可尝试更少分块（如 [6:9]）验证压缩/加速; 或探索是否可去掉累加只保留首步。
