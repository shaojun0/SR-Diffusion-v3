# SR-Diffusion v3 — v2 分块掩码 decoder 深度消融（d4, 4 层）训练 + 推理报告

> 日期: 2026-09-01 ｜ 分支: `main` ｜ 服务器: 2× RTX PRO 6000 (97GB), torch 2.12.1+cu130
> 本文档记录 block mask 架构下 decoder 深度 2→4 的消融实验：控制 lr 等其余超参不变，仅把 OutputQueryDecoder 从 2 层加深到 4 层。代码沿用 490dc08（Y_cum 梯度按步解耦为默认实现，无开关）。

---

## 1. 训练配置

| 项 | 值 |
|---|---|
| 架构 | DINOv2-large(不冻结, dim=1024) → OutputQueryDecoder(**nn.TransformerDecoder 4 层**, 分块掩码) → PixelHead（register 式, 无 ReEncoder） |
| 消融变量 | **decoder_depth 2 → 4**（对比 2 层版）；其余完全一致 |
| 分块掩码 | 每采样步 t 只 attend 自己所在的 z_s 块（块号 ⌊√t⌋）；第一个步可见自己块之前所有元素（含位置 0 = z_cls） |
| 集成 | 累加 + 梯度按步解耦（490dc08 默认实现）: Y_cum[n] = Σ_{t≤n} Y_t 数值不变，实现为 `[0, cumsum(Y)[:-1]].detach() + Y`——每步恰收 1 份自己那一步的梯度 |
| 采样切片 | `slice_start=4 / slice_end=9` → [25, 36, 49, 64, 81]（5 步） |
| 数据 | construction_site: 7009 训练 + 3004 测试（448×252, 576 patches） |
| 口径 | fp32、平权 mean、bs16/卡×2、**lr=1.5e-4 cosine（不变, 控制变量）**、40 epochs / 8760 步 |
| 产物 | `output/phase1_v2_block_d4/final_model.pt`（1.50GB fp32） |

## 4. 分析与结论

1. **decoder 深度 2→4 有正向收益（同代码口径下）**: 在同样的梯度解耦实现下，全量 L1 从 2 层的 18.77 降到 4 层的 18.25（-0.52），eval_loss 0.3272 → 0.3181（-0.009）。更深解码器整合分块信息的能力更强，补偿了部分梯度解耦带来的精度损失。
2. **但未回到无解耦水平**: 相比无梯度解耦的 2 层版（17.46 / eval 0.3045），4 层版仍高 0.79。梯度解耦削弱的"t=0 多份梯度动力"是主要精度损失源，深度加深只部分弥补。
3. **收敛更平稳**: eval 曲线 0.4708 → 0.3181 单调无波动；train_loss 0.4362 为三者最低（2 层无解耦 0.4374 / 2 层+解耦 0.4408），说明 4 层解码器拟合更充分。
4. **渐进曲线仍全平**: 5 步 18.23–18.25，分块信息第一步即充分，与 2 层版结论一致（深度不影响此性质）。
5. **代价**: 训练时长 2.9h → 3.6h（+0.7h），推理 153s → 161s，可接受。
6. **结论**: decoder 加深 2→4 在梯度解耦口径下带来稳定改善（18.77→18.25），但当前最优仍是无解耦 2 层版（17.46）。下一步可尝试 4 层 + 无解耦，或对解耦版调大 lr 补偿梯度总量。
