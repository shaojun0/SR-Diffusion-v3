# SR-Diffusion v3 — v2 分块掩码：单步独立推理测试 + 单步重训练消融（S25/S64）报告

> 日期: 2026-09-02 ｜ 分支: `main` ｜ 服务器: `connect.westd.seetacloud.com:25398`, 2× RTX PRO 6000 (97GB), torch 2.12.1+cu130
> 性质: 针对 `doc/2026-09-02/ANALYSIS_v2_all_failures.md`（e660e8d）"渐进曲线全平"根因的两组**新实证**：
> ① 在训练好的 5 步模型上做**单步独立（隔离）推理**；② 按单一变量规范**重训练"只有步25 / 只有步64"两个模型**并对比。
> 判据（用户给定）: 若单25 与单64 独立表现相同 → 各块携带等价信息（冗余问题）；不同 → 各块信息量不同（架构问题）。
> 数据: `doc/2026-09-02/single_step_data/single_step_results.json`（17 组全量 n=3004 结果 + 收敛轨迹）

## 0. 结论速览（TL;DR）

1. **重训练消融（最干净判据）: S25-trained = 19.15, S64-trained = 19.58 像素 L1——差仅 0.43（≈2.2%）。各块携带（近似）等价的信息。** 把步64 从"残差预测器"角色解放出来、作为主预测器训练后，它与步25 达到几乎相同的重建质量。
2. **原 5 步模型中"单步隔离"的巨大差异（单25=39.08 vs 单64=60.84，差 21.8）不是块信息量差异，而是累加训练的角色分工**：步25 被监督成主预测器（像素增量 |W·Y₁|=1.054），步36-81 被监督成残差≈0（像素增量 |W·Y_t|=0.015，特征被投进 PixelHead 近零空间）。单64/81 隔离时输出≈0/常数色（F_hat std≈0.08）→ L1≈61≈平均色。
3. **"渐进曲线全平"= 损失结构（累加 + 首步前缀规则）+ 查询间自注意力混叠共同作用**：5 步前向内第 1 步（经无掩码查询自注意力间接访问所有块）已达损失底（17.42），后几步增量≈0 → 曲线平。**与 ANALYSIS 结论①（损失前置最优）互相印证**；同时证明曲线的"平"**不是**由"各块信息量不同"造成的。
4. **z_s 冗余独立复测确认**：块内两两 cos=0.915、块5 vs 块8 跨块 cos=0.905（64 张 test）；与 ANALYSIS_v2_block_params_deep 的 0.947/0.9998 一致量级。
5. **5 步累加仍有真实但小的增益**：同预算下原 5 步模型 17.46 < 单步模型 19.15/19.58（约 -1.7~-2.1，~10%）——累加+混叠确实额外榨取信息，但全部作用于"第 1 步一肩扛起"上。

## 1. 背景与目的

- v2 分块掩码系列（block / block_r2 / block_d4）5 步累加渐进曲线**全平**（17.41–17.46），且 `z_s` 576 token 高度冗余（cos≈0.95）。
- 待裁决问题：全平是 **z_s 信息冗余**（各块携带等价信息）还是**架构**（累加/上下文混叠使各块信息量不同）？
- 用户判据：把训练好的模型分别用"只有第 25 步"与"只有第 64 步"单独跑（不累加）比较 L1 —— 相同 → 冗余问题；不同 → 架构问题。

## 2. 实验一：单步独立（隔离）推理测试（全量 3004 张 test）

方法：`test_single_step.py` 加载**同一份** `final_model.pt`（5 步训练产物），仅把 `decoder_steps` 改为单步（权重、数据、预处理、batch 完全一致；strict 加载）。
`mode=prefix`: 单步作为"首步"可见位置 0..hi（含 z_cls）；`mode=strict`: 仅可见自己块 [k²,(k+1)²-1]（关闭首步规则）。
原始 14 组结果见 `single_step_results.json`（键 `{model}|{steps}|{mode}`）。

| 模型 | 配置 | 归一化 L1 | 像素 L1 (0-255) | 说明 |
|---|---|---|---|---|
| block | 多步累加 prefix（基线） | 0.3054 | **17.46** | 与历史一致 ✓ |
| block | 单25 prefix | 0.6939 | **39.08** | 主预测器角色 |
| block | 单25 strict | 0.7045 | 39.70 | strict 几乎无差（+1.6%） |
| block | 单36 prefix | 1.0754 | 61.00 | ≈平均色 |
| block | 单49 prefix | 1.0659 | 60.45 | ≈平均色 |
| block | 单64 prefix | 1.0726 | **60.84** | ≈平均色（基线 61） |
| block | 单64 strict | 1.0698 | 60.67 | strict 几乎无差（-0.3%） |
| block | 单81 prefix | 1.0584 | 60.02 | ≈平均色 |
| block_r2 | 多步累加 prefix | 0.3278 | 18.77 | 梯度解耦基线 |
| block_r2 | 单25 prefix | 0.8047 | 45.54 | |
| block_r2 | 单64 prefix | 0.9980 | 56.54 | |
| block_d4 | 多步累加 prefix | 0.3185 | 18.25 | 4 层基线 |
| block_d4 | 单25 prefix | 0.8239 | 46.51 | |
| block_d4 | 单64 prefix | 1.1524 | **65.44** | 比平均色 61 还差（有偏常数色） |

单步完整曲线（block, prefix）= **阶梯函数**：25→39.08；36/49/64/81→60.0–61.0。

### 2.1 机制测量（block, 全部独立复测）

| 测量 | 数值 | 含义 |
|---|---|---|
| 5 步前向内每步**像素**增量 \|W·Y_t\| | [1.054, 0.015, 0.015, 0.015, 0.015] | 第 1 步=唯一主预测器；后 4 步增量≈0 → 曲线全平 |
| 同上，**特征**空间 \|Y_t\| | 全部 ≈1.065（不退化） | 后几步把输出学进 PixelHead 近零空间（R^1024→R^588 的核方向） |
| 5 步前向内逐累加 L1（128 张复测） | [0.299, 0.301, 0.306, 0.311, 0.317] | 重现"全平"（微升 +0.018） |
| F_hat 像素输出 std | 多步 0.84 / 单25 0.49 / 单64 0.083 / 单81 0.073 | 单64/81 隔离输出≈常数色 |
| z_s 余弦冗余（64 张 test 复测） | 块内两两 0.915；块5均值 vs 块8均值 0.905；逐 token 跨块 0.905 | 高度共线的全局摘要 |
| 同查询同交叉掩码(0..35)，5 步在场 vs 隔离 | 17.42 vs 39.08 | 22.5 像素差 = 纯查询自注意力上下文（混叠通道）效应 |

### 2.2 关键判读（实验一）

1. 单步隔离 L1 **显著不同**（39.08 vs 60.84）——但**不是**"块8 信息比块5 少"：单64 prefix 可见 0..80（信息严格更多）却更差；strict/prefix 几乎无差（掩码与可见 token 数不决定结果）。
2. 差异来源 = **训练角色**：步25 被监督为"主预测器"（直接 L1 对 target）；步36-81 被监督为"残差预测器"（输出≈0 增量），隔离时输出≈常数色 → L1≈61。
3. 单步 vs 多步（39.08 vs 17.46）同时改变了查询数量/自注意力上下文——这是**混叠通道**证据（同查询同掩码、仅上下文不同，22.5 像素差），佐证 ANALYSIS 的"上下文混叠"假设。
4. **结论：实验一本身不能裁决用户判据**（累加角色分工使隔离比较天然不等），需要实验二把角色变量消掉。

## 3. 实验二：单步重训练消融（单一变量，本次核心裁决实验）

### 3.1 设计

按用户要求用 `skip_steps/max_steps`（训练 CLI 的 `--slice_start/--slice_end`）控制步子集，重训练两个模型。调查确认原始训练实际为 **2 卡×16 = 有效批 32、`max_steps=8760` 封顶（=40 epochs×219 步/epoch）**，故本次用 bs32×1 卡 + 8760 步精确对齐预算，保证与 17.46 基线可对比；唯一变量 = slice。

| 项 | 原始 block（基线） | S25 | S64 |
|---|---|---|---|
| slice → steps | [4:9] → 5 步 [25,36,49,64,81] | [4:5] → **[25]** | [7:8] → **[64]** |
| 有效 batch / 总步数 | 2×16=32 / 8760 | 32 / **8760** | 32 / **8760** |
| epochs / lr / wd / warmup / seed | 40 / 1.5e-4 / 0.01 / 3% / 42 | 同 | 同 |
| decoder_depth / register / 输入 | 2 / True / 448×252 | 同 | 同 |
| 训练时长 | — | ~4.2h（GPU0） | ~4.2h（GPU1，并行） |

注：单步模型仅有的步自动触发"首步前缀规则"——S25 可见 0..35，**S64 可见 0..80（上下文严格更多）**；若上下文量是决定因素，S64 应占优，实际反之（见 3.3），进一步排除"上下文量"解释。

### 3.2 结果（全量 3004 张 test）

| 模型 | 归一化 L1 | 像素 L1 (0-255) | 相对 5 步基线 |
|---|---|---|---|
| 原 5 步 block（同预算） | 0.3054 | **17.46** | — |
| **S25-trained**（块5 独立训练） | 0.3342 | **19.148** | +1.69（+9.7%） |
| **S64-trained**（块8 独立训练） | 0.3418 | **19.576** | +2.12（+12.1%） |
| **S25 − S64** | **0.0076** | **0.428（2.2%）** | — |

训练期 eval_loss 轨迹（同预算逐步对比，归一化空间）：

| step | 原始 5 步 | S25 | S64 |
|---|---|---|---|
| 2000 | 0.4783 | 0.4722 | 0.4888 |
| 4000 | 0.4199 | 0.4099 | 0.4204 |
| 6000 | 0.3436 | 0.3601 | 0.3712 |
| 8000 | 0.3059 | 0.3352 | 0.3428 |
| 8760 (final) | **0.3045** | **0.3342** | **0.3418** |

（S25 在每一步都稳定领先 S64 约 0.008–0.017；n=3004 下像素 L1 均值 SE≈0.12，Δ0.43≈3.5 SE——真实但很小的块位置边际效应。）

### 3.3 判读（实验二）

1. **S25 ≈ S64（差 2.2%）→ 各块携带等价信息。** 按用户判据 → "渐进曲线全平是 z_s 信息冗余问题"——在"块信息含量"意义上成立。
2. **S64 可见上下文更多却反而略差** → 可见 token 数量不是决定因素；块5 位置/查询的边际质量略高于块8（50× 小于原模型角色效应）。
3. **5 步累加仍有真实增益（17.46 < 19.15/19.58）**：累加+查询自注意力混叠同预算下多榨出 ~10% —— 机制增益存在，但全部体现为"第 1 步（经混叠）一肩扛起"，故渐进曲线仍平。

## 4. 对 ANALYSIS_v2_all_failures.md（e660e8d）的呼应

| ANALYSIS 结论 | 本次实证 |
|---|---|
| ① 损失前置最优 → 曲线全平是损失结构强制的 | **直接证实**：5 步前向内 |W·Y₁|=1.054 vs |W·Y_t≥2|=0.015（后几步像素增量≈0）；重训练单步后 19.15/19.58 说明每块独立可达 ~19，全平是"第 1 步经混叠已到底" |
| ② z_s 无分工/冗余全局摘要 | **复测证实**：块内两两 cos 0.915、跨块 0.905；且各块独立训练质量等价（19.15 vs 19.58）——冗余是"每块都能独立支撑重建"的正面证据 |
| "各块信息量不同"（本次用户判据的另一支） | **证伪**：重训练消融下 S25≈S64；单步隔离差异完全来自累加角色分工（主预测器/残差），不是块信息 |
| 上下文混叠（查询间自注意力） | **量化**：同查询同交叉掩码下，5 步在场 17.42 vs 隔离 39.08（22.5 像素 = 纯自注意力上下文效应） |

## 5. 最终结论

1. **各块携带（近似）等价信息**（训练级证据：S25=19.15 vs S64=19.58，差 2.2%）。
2. **渐进曲线全平 = 损失前置最优 + 首步前缀规则 + 查询间自注意力混叠**共同作用的架构表象（证据：像素增量 70× 差异、在场/隔离 22.5 像素差），**不是**各块信息量不同的结果。
3. **单步隔离差异（39 vs 61）是训练角色（主预测器 vs 残差）的伪影**，不能作为"块信息量不同"的证据——若要测块信息，必须按实验二的方式独立训练各步。
4. 5 步累加提供真实但小的增益（~10%），但被"第 1 步扛全部"掩盖，渐进曲线无法展示增量——这正是指向 E2（逐 patch 内容查询）/独立步监督的架构修复动机。
