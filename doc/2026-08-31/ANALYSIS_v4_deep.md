## 结论速览

1. **数据可信**：0.1439↔8.26 换算自洽（0.1439×57.63=8.29，差 0.4%）；eval_loss 0.144 与全量推理 0.1439 同口径，且 v3/v4 两个版本的 eval_loss 比 = L1 比 = 0.465（完全一致）；train/test 分片分离、eval 单调无回升。**8.26 是干净的 held-out 数字**。
2. **"突破 9.8"机制方向成立但口径混用**：9.8 是旧模型冻结特征的**样本内线性**上限估计（32 张 test、同批拟合评估），8.26 是"微调 DINO + 非线性解码"的**端到端 held-out**（3004 张）；两口径不可直接对比。**真正干净的对照是 v3(17.77, 冻结) vs v4(8.26, 微调)**——解码器/损失/数据完全一致，2.15× 无需 9.8 参照也成立。
3. **归因缺口**：四格矩阵（编码器形态 × DINO 可训性）只占两格，缺 **"register+冻结"**（`train_v4.py --freeze_dino` 一键可跑）与 **"QFormer+微调"**（`train_v3.py --train_dino`）。2.15× 是两变量联合效应，无法拆分为"register 编码更好"或"DINO 微调更好"。
4. **z_s within-std 0.97→0.27 不能直接当"好信号"**：① 测量空间不一致（v3 z_s 无终层 norm，v4 z_s 经 dinov2.layernorm）；② "紧凑分工=好" vs "冗余升高=坏（Qwen context 浪费）"两种解读并存，需 token 级分析（有效秩/聚类）判定。
5. **对验收**：K=64 达 8.26（进入"好自编码器 5-8"区间边缘，该区间本身是推断参照）；但 **"活信息保真达标"尚无数值证据**（v4 缺边缘/std 数值、可视化未判读——8.26 含纹理成分）；DINO 微调的**语义漂移是 Phase 2 最大风险**，需语义探针 + Phase 2 预演验证。

## 2. "突破 9.8 上限"论断

- **9.8 口径**：32 张 test、旧特征目标模型的真实 DINO patch 特征、线性最小二乘、同批拟合+同批评估（样本内上限估计）。DIAGNOSIS §3.4.1 明确"属上限估计，新模型需重测"。
- **8.26 口径**：全量 3004 张 held-out、端到端（微调 DINO + 24 层深度编码 + 非线性注意力解码 + 2 层 MLP 头 + 40 epoch 监督）。
- **判定**：编码器状态、解码器容量、监督方式、样本量、拟合方式全部不同，**不可直接对比**。"8.26<9.8"数值成立，但"突破上限"是"旧上限 vs 新管线"的混比。
- **机制解释不唯一**【推断】：① 非线性解码比线性探针强，信息量未增也可更低；② 微调使特征"线性化"（差异方向对齐像素），下游更容易读而非信息变多；③ 9.8 样本内拟合偏乐观（但 18432 行≫1024 未知数，过拟合风险低）。
- **干净对照 = v3 vs v4**：2.15× 不需要 9.8 参照。严格归因需两个实验：v4 微调后 DINO 上重测线性探针（区分"信息变多"vs"解码变易"）+ register/冻结孪生（区分编码形态 vs 微调）。

## 3. v4 为什么比 v3 好 2.15×（归因）

- **变量拆解**：编码器形态（QFormer 2 层交叉注意力读冻结特征 vs register specials 经 24 层双向注意力深度编码）+ DINO 可训性（冻结 vs 分组 lr 1.5e-4/3e-4 微调）。
- **缺失单元影响**：四格矩阵只占两格 ⇒ 2.15× 是联合效应；无法排除交互效应（register 架构下 specials 梯度直接经 24 层流回 DINO，微调杠杆天然更大【推断】）。
- **z_s within-std 0.97→0.27**：测量空间混杂（v3 无终层 norm vs v4 有 layernorm，直接对比不严格）。两可解读：好（分工紧凑，GOAL 明确 576 冗余 z_s 对 Qwen 是 context 浪费）vs 坏（token 间冗余升高，若有效秩≪64 则压缩率名不副实）。8.26 + 均值探针 60.83 证明"信息在 token 间差异里、不在均值里"，但 0.27 能否承载语义需 token 级分析。
- **h within-std 0.45（v3 0.70）**：跨 patch 变异性下降但线性解码更好（17.03→8.88），提示微调后特征更"线性可解码"（差异方向对齐像素）【推断】。
- **判定**：现有证据支持"微调 DINO 贡献显著"（v3/v4 解码器同构），**不支持"register 编码本身有增益"**。

## 4. 对项目验收的意义

- K=64 达 8.26：进入"好自编码器 5-8"区间边缘（推断参照）。
- **K 扫描预期【推断】**：K=128 → 6.5-7.5（边际收益递减）；K=32 → 10-14（压缩压力陡增）。曲线形状 = "多少 token 够还原活信息"的标定，是 Phase 1 中间验收核心证据。
- **"活信息保真是否达标"目前不能判定**：8.26 是像素级 L1 含纹理成分；v4 报告无边缘保留/块内 std 数值；recon_visual_v4.png 未做数值判读。需 verify_visual.py 数值化 + 可视化判读。
- **Phase 2 启示**：① 编码器整体冻结（GOAL），v4 微调 DINO 已含"像素化扭曲"（GOAL §4.2 预警），7k 张同分布工地数据可能引入数据集先验特化【推断】，语义保持需实证；② z_s 紧凑对 Qwen context 效率可能有利（64 vs 576 token），但需确认 64 token 各携带不同语义；③ 验证路径：微调前后 DINO 特征相似度/可预测性探针 + Phase 2 预演。

## 5. 下一步实验设计

**P0（~3h GPU）**
- **P0-1 K 扫描 K=32/64/128**（v4 配置）：预期 32→10-14、64→8.26、128→6.5-7.5；判读：K=32≤12 且活信息保真 ⇒ 中间验收通过；K=32 崩坏 ⇒ 信息保持下限在 K=64 附近。两卡可并行两档。
- **P0-2 补齐四格矩阵**：register/冻结（`train_v4.py --freeze_dino`，~1.5h）+ QFormer/微调（`train_v3.py --train_dino`）。判读：register/冻结≈12-18 ⇒ 编码形态有独立贡献；≈17.77+ ⇒ 2.15× 几乎全来自微调。

**P1**
- **P1-1 Phase 2 预演**：冻结 v4 编码器 → MLP → Qwen 小批量文字（中文 image_caption/violations），对照 v3 编码器/原始 DINO 特征。直接回答"DINO 微调后特征是否仍适合 NLP"。
- **P1-2 v4 DINO 语义保持探针**（无训练）：a) 重测 9.8 式线性探针（微调后 patch 特征线性解码像素）：<9.8 ⇒ 信息真变多/更线性；≈9.8 ⇒ 增益来自非线性解码协同；b) 微调前后 DINO 特征相似度/线性可预测性（R²）量化语义漂移。
- **P1-3 z_s 逐 token 分析**（聚类/相关/有效秩 PCA）：判定"紧凑分工"vs"冗余"，决定 Phase 2 context 效率。

**P2**
- **P2-1** verify_visual.py 边缘/块内 std + recon_visual_v4.png 判读（活信息保真数值化，验收必需证据）。
- **P2-2** K=128/256 是否值得：先看 K 扫描曲线，若 128 边际<1.0 则 256 不值得（token 少是 NLP 优点）。
- **P2-3** 分组 lr 消融（dino_lr 5e-5/1e-4/1.5e-4/3e-4 冒烟级）：找"重建 vs 语义保持"折中，落地 GOAL 未决项②。
- **P2-4** 文字 CE 双目标（GOAL 未决项③）：Phase 1 叠加轻量文字 CE，直接练"能生成文字的 z_s"。

## 6. 风险清单

1. **口径混用（高）**："突破 9.8"混比旧模型样本内线性上限与端到端 held-out；结论表述需修正为"微调 DINO 的端到端结果低于旧冻结特征线性上限"，归因需孪生实验。
2. **DINO 语义漂移（高，Phase 2 直接风险）**：7k 张同分布数据微调可能特化数据集先验；test 同分布测不出；GOAL §4.2 已预警"像素化扭曲被永久固化"。
3. **z_s within-std 0.27 解读未定（中）**：紧凑分工 vs 冗余升高两可；测量空间不一致（v3 无终层 norm/v4 有 layernorm）。
4. **活信息保真未数值化（中）**：8.26 含纹理成分，缺边缘/std 数值与可视化判读，Phase 1 验收证据链不完整。
5. **探针样本口径（低）**：h/z_s 探针 128 条 vs 全量 3004，"h≈全量"是近似陈述。
6. **微调饱和 vs 欠拟合（低）**：ep36→ep40 仅降 0.0006（部分因 cosine 收尾），延长训练收益有限且增漂移风险。
7. **联想能力叙事（低-中）**：v4 无时序架构无 t≥1 平台曲线，联想能力需由 K 扫描曲线 + Phase 2 NLP 最终判定。
