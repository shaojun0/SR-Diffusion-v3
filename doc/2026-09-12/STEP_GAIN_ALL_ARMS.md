# 各采样 step 边际增益 — 全部臂完整对比（SR-Diffusion v3, 2026-09-12）

> 由 `gen_step_gain_all.py` 从 `data_stepid/` + `data_stepidcls/` 的 `STEP_GAIN_*.json` 生成，
> 无手工转录。口径：`cum` = 第 t 步**累积**输出的整图 0-255 像素 L1（越小越好）；
> `Δ` = cum[t−1] − cum[t]（**正 = 该步降低误差**）；`scale` = 第 t 步**原始增量** `mean|pixel_head(Y_t)|`。
> step1 无前序累积 ⇒ `Δ` 不可定义。**总落差 = cum[step1] − cum[step25] = Σ Δ(step4..step25)**。

单变量设计：四臂除「改动」外逐项相同（depth-4 系配置 `stack_dim 2048 / heads 16 / dropout 0.05 / lr 1.0e-4 / seed 42 / bs16×2卡 / 8760 步 / slice 0:5 (K=35) / blockdiag`）；`baseline` 为历史 depth-2 对照。臂① 为**零初始化** `step_embed`（默认路径逐位不变，实测 `max_abs_diff=0.0`）；臂② 为每步独立 `[cls]` 查询槽（输出切回 N 行，对外契约不变）。

## 4. 读法（结论摘要）

1. **符号**：baseline/stack2x 的 Δ16、Δ25 在 probe 与全量 test 上**全为负**（后步净有害）；
   臂① 使 Δ16 翻正、Δ25 大幅减负；**臂② 是唯一让 Δ16 与 Δ25 在全量 test 上同时翻正**的配置。
2. **量级**：臂② 后段 Δ 仅 +0.0015~+0.0047 px，是绝对误差（~21–25 px）的 ~0.02%；
   Δ4 仍占总落差的绝大部分（全量 test：Δ4 +0.0222 / 总落差 +0.0302 = 73%）。**无实质「后段分工」。**
3. **收益归属**：臂② 的聚合改善主要来自 **step1 单发读出变好**（全量 `head_mean`：stack2x 23.885 → 臂① 23.097 → 臂② 21.335；baseline 19.012），
   而不是后段变强 ⇒ 与「时间轴无正贡献、单发路线最优」的仓库战略判断一致。
4. **聚合**：`full_norm_l1` baseline 0.33179 / stack2x 0.41729 / 臂① 0.40316 / 臂② 0.37442；
   臂② 把 stack2x→baseline 差距填补 **50.1%**（臂① 16.5%），但仍落后 baseline 12.85%。
