## 0. TL;DR

1. **最短因果链**：损失把**每个采样步的累加结果都监督成整图**、且按步解耦 → step-1 的子任务=完整重建（16 键它真能做到 ~19.9，S25/S64 锚点 [数据]），后步子任务=预测"step-1 没做出来的残差" → 残差从后步可读的键里**不可预测**时，L1 的最优预测=零（条件中位数）→ 后步输出≈0 → 后区 register 永远收不到有效读出梯度 → 塌缩成 cos≈0.97 冗余簇 [数据] → 残差更不可预测 → **零增量自锁**。这是一个自洽均衡，不是某一层单独的病。
2. **机制裁决**：主因是"**最优解就是 0**"（损失/信息结构决定的均衡解），不是"训练动力学锁死"（exp2/3151bab 式全塌缩只是同族吸引子的极端形态），也不是"想学但没手"（S25/S64 证明：单步给足 36–80 键和独占梯度能到 ~19——后步是**没活干**，不是没能力学 [数据]）。
3. **解耦/不解耦与后步归零无关**：两种梯度制度下后步都≈0（plain cumsum 的 block 模型实测 |W·Y_t|=[1.054, 0.015×4] [数据]）。17.46<18.77 是共享参数**更新方向**之争（step-1 唯一有效通路分到的更新份额），不是后步被饿死。
4. **要后步真干活，最小改动=每步私有目标×私有信息的联合改造**（首选分区域掩码损失；F1/E2' 编码侧注入是信息侧前提；残差显式化单独无效——零仍是残差不可预测时的最优）。**战略判断：直接走 v4 单发路线（8.26）**——渐进阶梯不在 GOAL 验收内，Phase-2 一次性消费全部 K token，时间轴 6 轮证伪后只剩负资产。

## 1. "后步不工作"的最短因果链（分层 + 权重）

权重大小为主观估计，且各层**不独立**（L2 是 L1/L3/L5 的果又是 L1 的因，见 §2.3）：

| 层 | 机制 | 证据 | 权重 |
|---|---|---|---|
| **L1 损失/目标结构** | 每步累加结果都监督**整图** + 平权 + 按步解耦 [代码 decode(): `per_step=mean L1(cumsum_t,target)`; `carry.detach()+Y`] ⇒ step-1 独扛是近全局最优，后步的最优=零增量（§2.1）；L1 是 ±1 恒定符号梯度、无幅度信息，**猜错的代价=猜对的收益**，不确定时保守归零 | [代码]+[数据: step_px_scale slice05=1.007/0.06×4, slice27_v2=1.02/0.09…0.06] | ~40% |
| **L2 键信息供给** | 后步读区 register 塌缩：slice27_v2 位置 16..63 两两 cos 0.963–0.974、采样种子 cos 0.998–0.9999；slice05 within-std 0.053（=slice27_v2 的 1/3）[数据]——后步即使想输出残差，读到的键也没有增量内容 | [数据: probe json / E1] | ~30% |
| **L3 读出/查询结构** | F3/F4：固定 query_base 模板 + 共享键凸组合 + 共享 FFN，无逐 patch 内容句柄 [代码]；单步直读上限 ~19（S25=19.15/S64=19.58 [数据]）——**即使键健康，后步也没有超过 step-1 已达水平的净空间**。唯一突破过该上限的通道是跨步行自注意力混叠（在场 17.42 vs 隔离 39.08，22.5 像素差 [数据]），已被因果 tgt_mask 堵死 | [代码]+[数据] | ~20% |
| **L4 共享头/特征空间累加** | 累加在非线性特征空间、头只过一次（含 bias）[代码] → R¹⁰²⁴→R⁵⁸⁸ 的近零空间给"零"提供了完美藏身处：\|Y_t\| 特征 ≈1.065 不退化，\|W·Y_t\| 像素 ≈0.015 [数据]。不是病因，是"零"能做得**干净无代价**的使能条件 | [代码]+[数据] | ~5% |
| **L5 训练动力学自锁** | 后步≈0 → 后区键只经≈0 输出路径收梯度（弱且方向不一致）→ 键趋同 → 注意力均匀 → 残差更不可预测。exp2（读侧全开）/3151bab（块级共享位置）在 lr 峰值附近整体塌缩到 grad≈0.001 [数据]，是同族吸引子的**全身版**；正常 run 里分块读给 step-1 保留了排他读出压力，把退化**局部化**到后步 | [推断]+[数据] | ~5% |

注意 L2 的 register 并非"梯度死区"：它们经 DINO 24 层全双向注意力参与前向/反向（花瓶区梯度 9.81>读窗口 6.35、砍花瓶 K=99 反而差 [数据 09-02]）——但它们被雇佣为**编码器草稿纸**，梯度奖励的是"做同质中间计算"，不是"携带可读的差异内容"，产物就是冗余全局摘要 [推断]。

## 2. 核心机制裁决

### 2.1 "最优解就是 0"——成立，是主因 [推断，结构为代码事实]

解耦后第 t 步面对的精确问题是：`min L1(PixelHead(c_t.detach()+Y_t), target)`，c_t=前 t−1 步累加。step-1 收敛后，残差 r_t=target−pixel(c_t) 是重建器做不到的高频部分。后步要把 r_t 拉进自己的输出，需要其键携带"step-1 前缀之外、且能逐 patch 定位"的增量信息。当键不含此信息时，r_t 关于后步输入的条件分布≈无条件分布——逐像素近似零均值、符号对称——**L1 的最优预测=条件中位数≈0**。L1 的 ±1 恒定梯度使"猜"的期望收益为零、方差为正，归零是唯一无风险解。L4 的近零空间让该解可以被精确、稳定地实现（常数特征向量藏进 PixelHead 核方向，输出逐图不变地≈0 [数据]）。

### 2.2 "想学但没信号"——不成立为主因 [数据]

S25/S64 独立重训是同栈、同掩码规则、单步独占全部梯度：36/80 键 → 19.15/19.58。证明"读出器+键"这个器官**能学**，且学得和 step-1 一样好。后步的问题不是没有手，是 step-1 已经把活干完了（它做到 ~19.9=该栈读出上限），剩下的残差里**没有后步可预测的分量**。键塌缩（想学没内容读）真实存在，但它是 §2.3 循环的果；即使把键修健康，L3 的 ~19 读出上限仍让后步无净空间可加——"没信号"层最多解释"为什么均衡如此干净"，解释不了"为什么没有活"。

### 2.3 "训练动力学锁死"——是锁定机制，不是第一因 [推断]

三者互相强化成鸡生蛋：**损失结构定义了"后步只能捡残差"的游戏（L1）→ 后步捡不动 → 输出≈0 → 后区键收不到有效读出梯度（L5）→ 键塌缩（L2）→ 残差更不可预测 → 零更优**。动力学是胶水不是砖。同理可证反方向：只要某一步能稳定拿到"只有它能预测"的监督信号，该循环就反向转动（键被读出压力养出分工）——这正是 §4 改法的设计原理。

### 2.4 为什么旧 14.28 里 step-1 能靠池化后步行状态工作、而后步自己仍≈0？[数据+推断]

旧 slice27（无因果 tgt）损失结构相同，后步**输出**同样≈0——它们的角色是**中继**：第 1 层交叉注意力后，步 2..5 的查询行状态已"身怀"各自块的内容，第 2 层全双向行自注意力让 step-1 把这些状态池化进自己输出（22.5 像素差 [数据]）。中继不需要自己的输出非零——**损失只监督输出 Y_t，从不监督中间行状态**。更关键的是，这条中继同时是后区 register 的**梯度补给线**：旧模型后区 cos 0.90–0.92，因果化堵死中继后补给线断、塌缩加剧到 0.96–0.97 [数据]——一个改动同时杀了推理通道和训练压力，这解释了 14.28→19.88 的跌幅为何超过"少一个池化通道"的朴素预期 [推断]。

## 3. 解耦 vs 不解耦 与后步归零的关系

- **定量关系**：plain cumsum 下 dL/dY_t 来自第 n≥t 步全部损失项（三角权重：Y₁ 收 5×、Y₅ 收 1×）；解耦后每步恰收 1× [代码+自检]。
- **17.46(plain) < 18.77(解耦) 的重新解读** [推断]：不是"后步被解耦饿死"——plain 下后步同样≈0（|W·Y_t|=[1.054,0.015×4] 实测于 plain 的 block 模型 [数据]）。差异在**共享参数的更新方向**：解码器 stack/编码器是 5 步共享的，解耦把 80% 的步梯度预算花在 4 个"最优=零"的任务上（这些梯度不小，它们把共享权重和 register 写作习惯推向"让后步安全输出零"）；plain 的三角权重让 step-1 的任务主导共享更新 → step-1 通路收敛更充分。step-1 输出 scale 在两种制度下都≈1.0（量级易得、质量难得），与"饿死"不矛盾——饿的是质量不是幅度。此解读与用户指出的事实 8 自洽。
- **因果族里 plain cumsum 能否激活后步？** [推断] 不能。step-1 瓶颈是掩码给的可及范围（0..15）而非梯度预算，5 倍梯度突破不了 ~19.9；后步梯度权重升 4–5 倍，但读的是 cos≈0.97 塌缩簇、无可修残差。预期 L1 改善 ≤1、曲线仍全平、step-1 独扛更彻底（three_configs §2.2 同判）。⚠️ 实验注意：plain 下 Y₁ 等效 lr ×|T|，对比须同步调 lr，否则不可比。
- **一句话**：后步归零对梯度制度**不变**——它是信息/损失结构的性质，不是梯度分配的性质。梯度再平衡这条线 09-01 已用 17.46→18.77 关过一次门，本问不例外。

## 4. 若要后步真正"逐级加信息"：最小改动评估（含排序）

判据：任何改法必须同时打破"零是最优"（损失侧）和"无可预测残差"（信息侧），否则鸡生蛋循环原样重启。

| 排序 | 改动 | 成本 | 预期/风险 | 验证判据 |
|---|---|---|---|---|
| **P1（首选，若坚持渐进）** | **分区域掩码损失**：step t 只监督自己对应的 patch 行区（如 576 行均分 5 区），去掉整图平权累加损失；保留块因果读 | 代码 ~20 行 + ~2 GPU·h 重训 | 每步有了 step-1 抢不走的私有目标；键/区比从 16 键:576 patch 改善到 ~10 键:~115 patch，低于 S25 锚点的难度；损失本身产生 register 分工压力（不用额外正则）。风险：最终整图 L1 未必优于 19.88（这是为"真阶梯"付的价）；F3/F4 读出上限仍在 | ① 各步**隔离** L1 在自己区域上相近（不再 39 vs 61）；② 累加曲线出现真阶梯（覆盖区单调降）；③ 后步 \|W·Y_t\| ≫0.015；④ z_s within-std 从 0.14 回升、16..63 cos 明显跌破 0.9 |
| **P2（信息侧前提）** | **F1/E2' 编码侧注入**：special 输入拼 Linear(patch_feat)；可叠加正交/负余弦/使用率正则 | 1–2 天 + 调参 | 唯一直接治 L2 的改法；P1 若在 ~19 读出上限处 stall，病灶就在此。无成功保证；不在 GOAL 验收内 | E1 复测：h 线性显著 <20 或模型进 <19；键 cos 结构性下降 |
| **P3（组件，单独无效）** | **残差目标显式化**：target_t=target−stopgrad(pixel(cumsum_{<t})) | 小 | 现解耦损失已**隐式**给残差梯度（L1 过共享头的梯度就是当前残差的符号场）；显式化不改变"残差不可预测→零最优"。只有配 P1/P2 才有意义 | 单独跑预期≈不动（此预期本身可作零成本证伪实验） |
| 不推荐 | 去解耦/后步加权 | ~2 GPU·h | §3：梯度制度不变量，历史已证非杠杆 | — |
| 不推荐 | 去共享头 bias/改像素空间累加 | 小 | 只是拆掉 L4 的藏身处（诊断意义有，机制意义无）：零仍最优，只是藏得没那么干净 | — |
| 不推荐 | 课程式 fade-in | 中 | 无私有目标/信息时，只推迟同一均衡的到来 | — |
| **战略（推荐）** | **承认渐进不是目标，走 v4 单发** | 复用现成配方 | 8.26 已是仓库最佳；GOAL §2 验收=K 压缩×重建+Phase-2，渐进阶梯**不是验收项**，Phase-2 一次性消费全部 K token。时间轴对重建的全部历史贡献=给 step-1 一条中继（14.28，仍输 8.26）+ 制造塌缩 | GOAL 口径 |
