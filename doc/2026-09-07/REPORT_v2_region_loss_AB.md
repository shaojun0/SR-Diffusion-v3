## 0. TL;DR

1. **机制层面：分区掩码损失成功打破"后步≈0"自锁**——后步输出量级 step_px_scale 从 B（旧全图损失）的 [1.05, 0.09-0.11×4] 变成 A 的 [1.34, 0.61, 0.30, 0.46, 0.42] [数据]；region×step 误差矩阵出现**对角阶梯**（每步把自己那片区域修到局部低误差 ~11-22）；z_s register 分工显著改善：within-std 0.20→**0.56**、尾区(16..63) 平均 cos 0.78→**0.49**（不再塌缩成冗余簇）[数据]。**"后步不工作"的根因（无私有目标）被 P1 命中。**
2. **但整图质量大幅变差（结构性缺陷, 非参数/预算问题）**：A 全量 3004 像素 L1 = **42.34**, B（复现历史）= **19.66**（历史 slice27_v2=19.878, 差异≈1% 为口径近似）[数据]。原因 = **后步在自己区域之外的行无任何监督 → 自由漂移 → 污染先前步已修好的区域**（region 矩阵实锤: region0 误差 步1=11.3 → 步5=65.1; region1 16.4→53.1）[数据]。这正是 `DESIGN_v2_region_loss.md` §6.1 预警的风险 F1, 本次被实验证实。
3. **结论**：P1 方向正确但当前实现缺一个"区域互斥/零锚"约束；下一步实验 = 在区域外行上加零锚（或改为只对各自区域贡献的读出结构）, 预期可同时保留阶梯与整图质量。这不是死路, 是 P1 的 v2 迭代。

## 3. 关键证据：region × step 误差矩阵（0-255 L1, 行=第 i 步累加, 列=目标区域 r）

**A_region:**

| 步\区域 | r0 (行0-114) | r1 | r2 | r3 | r4 |
|---|---|---|---|---|---|
| 步1 | **11.32** | 38.17 | 58.65 | 60.83 | 64.25 |
| 步2 | 35.48 | **16.35** | 47.01 | 55.11 | 58.78 |
| 步3 | 53.14 | 41.66 | **20.89** | 44.21 | 44.39 |
| 步4 | 63.48 | 49.27 | 40.07 | **22.32** | 36.25 |
| 步5 | 65.11 | 53.10 | 40.94 | 30.96 | **21.77** |

**B_full（对照）:** 每行 = [15.70, 19.17, 23.22, 20.56, 19.64]（全平, 无阶梯无对角）[数据]

- **A 的对角阶梯 = 分区机制生效**：步 t 把自己的区域修到 ~11-22（对角线), 该行其他区域未覆盖(高)。
- **A 的反对角污染 = 结构性缺陷**：region0 误差随步递增 11.3→35.5→53.1→63.5→65.1（步 2..5 在 region0 行的输出无监督、自由漂移并叠加进累加）；region1 同理 16.4→53.1。→ 最终整图(步5 行)被前区污染拖到 42.3 [数据+推断: 机制见下]。

### 3.1 缺陷机制（与 DESIGN §6.1 风险 F1 对应）[代码+数据]
当前实现 = 在**共享的全行输出 Y(B,T,N,D) + 特征累加**上做区域掩码监督: 第 t 步只监督 `Y_cum[:,t, region_t]`, 但 `Y_t` 在 `region≠t` 的行**不在任何损失里**(解耦 carry.detach 后更无间接梯度) → 这些行只被共享权重/衰减驱动 → 数值上自由漂移; 而 `F_pix=PixelHead(Σ_t Y_t)` 每行都加上了全部步的输出 → 先被修好的区域被后步漂移破坏。B(旧损失)没这个问题是因为每步监督整图, 漂移会被损失拉回; A 的区域掩码把"维护其他区域"的责任删了。

## 4. 结论与下一步

1. **P1（分区掩码损失）机制验证成功**: 打破后步零输出自锁、恢复 register 分工——回答了"后步不工作"的根因, 修法方向正确。
2. **当前实现不达标**: 整图 L1 42.3 (2.15× 于 B), 因缺少"区域互斥/维护"约束; 需要 P1-v2 迭代, 候选改动（按成本排序, 均 ~2 GPU·h/档 + 代码小改）:
   - **(a) 区域外行零锚**: `loss += λ · mean|Y_pix_raw[:, t, rows∉region_t]|`（或等效: 只让每步在自己区域行上输出, 其他行强制≈0）——预期: 消除反对角污染, 整图 = 各区域局部最优拼接, 阶梯保留;
   - **(b) 全程维护监督**: 每步同时轻监督"已覆盖区域保持"(如 step t 也监督 region<t 不劣化, λ 小);
   - **(c) 改读出结构**: 每步只对 region_t 行产生输出（结构性互斥, 改动最大）。
   - 验证判据: 整图 L1 < 20 且对角阶梯保留(region 矩阵对角线 ~11-22、非对角不再随时间上涨)。
3. **战略判断不变**: 若最终目标不含"token 增量性"叙事, v4 单发读出(8.26) 仍是主线; 本线只为"真渐进语义"服务。
