# 采样计划对照：平方块（步值 k²）vs 固定 4（步值自然数、每步读 4 个）—— **固定宽度在高 N 上训不起来**（2026-09-23）

> 用户口径（第二轮）：「现在 t 不再是按 1 4 9 16 进行增长，而是按自然数的形式增长，再继续一下上面的实验。」
> → 追问后定案：原本想做「每步读 1 个 token」（\|T\|=N），**确认不现实**后改为 **每步固定读 4 个 token**。
> 机器：AutoDL bjb1 **1× A800-80GB**；代码 = `main`@`05d380b` + 本会话新增的 **opt-in `--step_plan`**（默认路径不变）。
> 预算沿用上一轮：**A 相 3000（单步全读）+ B 相 7000 = 总 1 万优化步**，5 个分辨率全跑。
> 产物：[`rerun_fixw4_10k/`](rerun_fixw4_10k/)｜墙钟 **5 h 54 m**（336² 独占 4 h 26 m）。

## 0. 一句话结论

**「步值按自然数增长 + 每步固定读 4 个」这个计划在高分辨率上直接训不起来 —— 不是略差，是卡在平凡解。**

| 分辨率 | \|T\| 平方块→固定4 | 平方块 best PSNR | **固定4 best PSNR** | **Δ** | 固定4 是否跨过平凡解 |
|---|---:|---:|---:|---:|---|
| 28² | 2 → 1 | 25.09 | **25.88** | **+0.79** | ✅（但 \|T\|=1 已退化） |
| 56² | 4 → 4 | 25.50 | **25.40** | −0.09 | ✅ |
| 112² | 8 → 16 | 24.71 | **21.86** | **−2.86** | ✅（+5.16 dB） |
| 224² | 16 → 64 | 19.59 | **16.09** | **−3.51** | ❌ **−1.26 dB（低于基线）** |
| **336²** | 24 → **144** | 17.62 | **13.58** | **−4.03** | ❌ **−4.25 dB（低于基线）** |

- **差距随 N 单调增大**，56²（两计划 \|T\| 相同）相等，112² 起才开始输；
- 224²/**336² 的固定臂 B 相全程贴在低水平**（224² 从 13.65 只爬到 16.09，平方块同期 13.58→19.59；
  336² 更差：13.24→**13.87（B3000 峰值）**→13.58 回落），而 336² 的 **DC 平凡解基线是 21.37（L1）**
  —— 与旧扫描「停在预测均值」是**同一个失败模式**，只是这次不是因为 A 相预算，而是因为**B 相本身的读法**；
- **代价同时更高**：336² 从 65 min 涨到 **4 h 26 m（4.06×）**，换来的却是 −4.03 dB。

> ⚠️ 顺带一个**方法学发现**（本会话实测）：这套训练**不是逐位可复现的**，同一 seed 重跑会漂移；
> 但终点漂移只有 **0.1–0.3 dB**，远小于本轮的 2.9–4.0 dB 差距 ⇒ **上述结论不受复现性影响**（详见 §4）。

## 1. 口径：什么是「固定 4」

读窗口的几何统一收在 **`model_v2.step_windows()`**（新函数，模型与工具共用）：

| | `plan="square"`（历史唯一口径，默认） | **`plan="fixed"`（本次新增，opt-in）** |
|---|---|---|
| 步值 | `1, 4, 9, 16, …` = **k²** | **`1, 2, 3, 4, …` = k** |
| 步数 \|T\| | √N → 2 / 4 / 8 / 16 / 24 | **N/4 → 1 / 4 / 16 / 64 / 144** |
| 第 k 步读 | `z_s[k² : (k+1)²]`，宽 **2k+1** | `z_s[(k−1)·4 : k·4]`，宽**恒 4** |
| 首步 | `lo=0`（额外含 `z_cls`）⇒ 宽 2k+2 | `lo=0` ⇒ 宽 **5** |
| 末步 | **退化为 1 个 token**（K=N 截断） | **无退化**（均匀铺满，末尾可截断） |
| K | N | N（**不变**） |
| 终点累计读入 | N+1 列 | N+1 列（**终点相同**） |

**⇒ 唯一变量 = 读的节奏**（架构 / K / A 相 / 终点码率全同）：同样是读满 N 个 `z_s`，
平方块用 √N 步"大步跨"，固定 4 用 N/4 步"小步挪"。

> 实现是 **opt-in**：`step_plan` 默认 `"square"`，默认路径与改动前**逐位一致**
> （从 `HEAD` 取旧 `model_v2.py` 对比：权重逐位相同、前向 `max|diff| = 0.0`、读窗口一致）。

## 3. 机制：为什么"步更多、窗口更小"反而训不起来

这一条**印证而不是推翻** `ANALYSIS_res_sweep_rootcause.md` §2(e) 的机制：

> B 相 = 「**切块读**、**整图预测**」，早期步的窗口（这里恒 4~5 个 token）能提供的条件信息极少，
> 而每一步都被**平权**要求还原整张图 ⇒ 每一步的条件最优解都接近"预测均值"；
> **步数越多，这个"糊"的梯度在总损失里占比越大**。

- 平方块计划下，窗口宽 **2k+1** 是**递增**的：最后几步一次读 31–47 个 token，这几步的梯度是"锐"的、
  能把表示往细里推（336² 的 21/23 步严格下降就是这个"逐步变锐"的轨迹）；
- 固定 4 计划下，**144 步全部只有 4 个 token**，没有"后期变锐"的步骤
  ⇒ 整条轨迹被 144 个"只能猜均值"的损失项主导，模型直接收敛到平凡解；
- 这正好解释了**差距随 N 单调增大**：N 越大 \|T\|=N/4 越大、而窗口恒为 4（相对 N 越来越小）。

**⇒ 可检验的推论（下一步）**：把窗口做成**递增但仍按自然数步值**（第 k 步读 k 个 = 三角数累积，
N=576 → \|T\|=34），应当介于两者之间 —— 即"自然数步值"本身不是问题，**"窗口不增长"才是**。
这也把交接 §7⑤「步间损失按窗口加权 / 早期步监督低通目标」的动机又推进了一步。

## 4. ⚠️ 方法学发现：这套训练**不是逐位可复现的**（实测，两处独立证据）

做「A 相一致性校验」时发现两臂 A 相数字对不上（本应逐位相等）。逐项排查后**排除了实现问题**：

| 排查项 | 结果 |
|---|---|
| 两计划下**模型权重初始化** | 参数 sha256 **完全相同**（`6d7f2ff07d285658`） |
| 两计划下 **A 相读窗口**（`steps=[N]`） | 都是 `[(0, 576)]` |
| 两计划下 **A 相同权重同输入前向** | `max|diff| = 0.0` |
| 两计划下 **数据顺序**（seed 42，前 6 个 batch 哈希） | **逐位相同** |
| **同一配置重跑两次**（336²，1200 步 A 相） | **不同**：A800 L1 38.29 vs **39.06**；A1000 37.18 vs 37.39 |

⇒ **训练本身有非确定性**（未设 `cudnn.deterministic` / 未固定 SDPA 后端，疑似 attention backward 的原子加），
且**在 A→B 逃逸分叉附近会被放大**（336² A2500：18.82 vs 16.00 dB，差 2.8 dB）。

**但它不影响本轮结论** —— 把 112² 两臂**各完整重跑一遍**测终点漂移：

| 112² 臂 | 原跑 best PSNR | 重跑 best PSNR | **终点漂移** |
|---|---:|---:|---:|
| 平方块 | 24.71 | 24.61 | **0.10 dB** |
| 固定4 | 21.86 | 22.16 | **0.30 dB** |
| **两计划差距** | | | **2.86 dB** |

⇒ **终点漂移 0.1–0.3 dB ≪ 干预效应 2.9–4.0 dB**（且 336² 的差距是 L1 37.8 vs 21.76 的**类别级**差异）。
**结论：采样计划的影响真实且显著；分叉附近的单点数字（如 A2500）不可当精确值用。**

## 5. 边界（不能说的）

1. **单 seed**（本轮的"重复"只做了 112² 两臂各一次 + 336² A 相两次；224²/336² 终点未重复）。
2. z_s = **patch token 而非 register**、**DINOv2-small**、depth=2、β=1 名义 bpp ⇒ 不是仓库主线复现。
3. **28² 是退化点**（固定 \|T\|=1），**56² 两计划 \|T\| 相同** ⇒ 真正的对照只有 112²/224²/336² 三个点。
4. 336² 仍用 bs8×accum2（B 相峰值显存 **72.4 / 80 GB**，形状静态、全程 0 OOM）；
   固定 4 计划的显存约为平方块计划的 4–6×，**这是它 4.06× 变慢的同源原因**。
5. bpp 主表用名义 `t+1` 口径（与历史曲线可比）；本目录同时存了 `bpp_actual`（实际累计读入）。
   注意固定 4 计划下名义 bpp 与实际的差距≈4×，**看 RD 必须用 `bpp_actual`**。
6. 未做：递增窗口臂（§3 的推论）、固定 2 / 固定 8、去相位臂、种子重复。
