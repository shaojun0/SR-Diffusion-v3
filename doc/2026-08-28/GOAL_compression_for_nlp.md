## 0. 一句话目标

**通过 token 压缩训练编码器的"联想能力"，训练完成后冻结编码器，作为
`model.py` 的编码器进行 NLP 解码训练（Qwen 生成中文工地描述/隐患）。**

像素重建（当前 Phase 1 的监督信号）是**训练脚手架 + 信息保持的直接探针**：
它证明并迫使"少量 token 编码了整图信息"（语义是像素的函数 ⇒ 能还原像素 ⇒
z 携带语义信息），为 Phase 2 NLP 提供信息基础。重建本身不是最终指标，但
**不是**与 NLP 对立的——只有"纹理级清晰度"（死信息）才不追。

---

## 1. 两阶段链路

```
Phase 1（当前）: DINOv2(不冻结?) → ReEncoder → z_s ──像素重建 L1──  ← 练"压缩+联想"
Phase 2（后续）: 冻结 DINOv2 + ReEncoder → z_s → MLP → Qwen → 中文描述/隐患  ← 唯一验收
```

- Phase 1 产物: 训练好的编码器（DINOv2 + ReEncoder + specials），输出 z_s；
- Phase 2: 编码器**整体冻结**，z_s 经 MLP 投影接入 Qwen（范式同 `model.py` 的
  SVDEncoder→MLP→Qwen，只是把 SVD token 换成 z_s）。

## 2. 成功标准（按目标重定义，勿被像素 L1 带偏）

| 指标 | 是否目标 | 说明 |
|---|---|---|
| **NLP 文字生成质量**（中文描述/隐患） | **是（唯一验收）** | Phase 2 冻结编码器后 Qwen 输出质量 |
| 联想能力（少 token 还原全图） | 是（Phase 1 训练目标） | t=1≈t=576 平台证明**已成立**（K 压缩下需重验） |
| **信息保持（重建可验证）** | **是（必要条件）** | 能还原像素 ⇒ z 携带整图信息（数据处理不等式；语义是像素的函数）。重建质量是信息保持的直接探针，**决定 NLP 天花板**。Phase 1 中间验收 = **K 压缩 × 重建质量**（K=32/64/128 下"活信息"=布局/物体/边界的保真度） |
| 像素重建 L1 (23.4, K=N) | 否（非最终指标，但必要） | 与 9.8 上限的差距主要是块内纹理——按 [3] 属死/冗余信息，不追；但它证明信息链路已通，且像素压力必须保留（防特征目标退化假收敛） |
| 重建清晰度/边缘（纹理级） | **否** | 纹理是 [3] 意义上的死/冗余信息；但**活信息（布局/物体/边界）在 K 压缩下的保真是 Phase 1 核心验证**——"追重建"与 NLP 不冲突，冲突的只是纹理 |
| 当前 K=N=576（零压缩） | **未验证目标形态** | 尚未做"少 token 编码最多信息"的验证；旧 k-sweep 基于特征目标模型，不可直接外推 |

**推论**:
1. "重建糊"（L1=23.4、边缘≈1/3）的**纹理部分**不是要修的目标——低频/中频
   （颜色、布局、物体、场景）都保住了，那才是 NLP 需要的；但**活信息保真
   是目标**（K 压缩下验证），不因"不追纹理"而停止信息保持训练；
2. t≥1 平台（2 键 ≈ 577 键）是**联想能力已工作**的证据，不是缺陷；在 K
   压缩下重验后即为 Phase 1 验收证据；
3. 真正的结构问题是**冗余**：576 个 z_s 全是"全局摘要的副本"，对 Qwen 是
   context 浪费（同一句话重复 576 遍）——压缩率 K 才是"练联想"的真正杠杆；
   [3] 表明 dead 的是**冗余 token**（多数 token 塌缩为同一背景），不是图像
   信息少——压缩后信息是否保住，必须用重建验证。

## 4. 未决决策（讨论中，勿当已定）

1. **压缩率 K（special 数量）取多少**：候选 32/64/128。k-sweep 显示 32 已够还原；
   固定 K 即可，不必复活 SelectHead 预算机制（YAGNI）。**K 压缩 × 重建质量实验
   是 Phase 1 的核心验证**（当前 K=N=576 零压缩，尚未验证"少 token 编码最多
   信息"；旧 k-sweep 基于特征目标模型，需重做）。
2. **DINO 冻结 or 低 lr or 维持现状**：Phase 2 要整体冻结编码器 → Phase 1 里 DINO
   学到的"像素化扭曲"会被永久固化。候选: 冻结 DINO（只训 ReEncoder+头）/
   分组低 lr（DINO 1e-5~3e-5，新模块 1.5e-4~3e-4）。
3. **Phase 1 是否叠加轻量文字 CE 双目标**：数据有 `image_caption`+`violations`
   中文标注；TextDecoder 以前写过（git `e22c42c`/`e7087f4`），像素目标重构时被移除。
   文字 CE 是"直接练联想"的信号（编码器必须产出能生成文字的 z_s），像素 L1 负责"别丢信息"。
4. **验收实验设计**：冻结 → MLP → Qwen 小批量训文字，看中文描述质量。

---

## 5. 下一步建议（按目标排序，待用户拍板）

1. **P0｜K 压缩 × 重建质量实验**（信息保持验证，Phase 1 核心）：special 数
   576 → 32/64/128 重训，在像素目标模型上标定"多少 token 够还原活信息"
   （布局/物体/边界保真 + 像素 L1），预期 K=64 接近现状且 z_s 不再冗余。
   这是"少 token 编码最多信息"的直接证据（旧 k-sweep 不可外推）。
2. **P1｜NLP 就绪探针**：把冻结编码器的 z_s 接入 model.py 式 MLP+Qwen，小批量训
   文字，验证信息可被语言头读出、链路能生成对的中文描述——最终唯一验收。
3. **P2｜按 §4 决策落地**：K + DINO 策略 + 是否文字 CE。
