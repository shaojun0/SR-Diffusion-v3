# 各采样 step 边际增益 — 全臂统一对比 v2（含 depth-8 臂①，SR-Diffusion v3, 2026-09-14）

> 由 `gen_step_gain_all_v2.py` 从四个 `data_*/STEP_GAIN_*.json` 生成，**无手工转录**。
> 口径：`cum` = 第 t 步**累积**输出整图 0-255 像素 L1（越小越好）；`Δ = cum[t−1] − cum[t]`（**正 = 该步降低误差**）；
> `scale` = 第 t 步**原始增量** `mean|pixel_head(Y_t)|`。step1 无前序累积 ⇒ Δ 不可定义。**总落差 = cum[step1] − cum[step25]**。

单变量设计：depth-4 系各臂除「改动」外逐项相同（`stack_dim 2048 / heads 16 / dropout 0.05 / lr 1.0e-4 / seed 42 / bs16×2卡 / 8760 步 / slice 0:5 (K=35) / blockdiag`）；depth-8 系两臂为 `lr 7.6e-5 / bs8×accum2 / 8760 步`。`baseline` 为历史 depth-2 对照。臂① 为**零初始化** `step_embed`（训练起点与无注入逐位一致）；臂② 为每步独立 `[cls]` 查询槽；臂④ = 臂② **+** 臂①。**臂①@d8 与 stack8x 构成唯一单变量对照（仅差 `step_embed`）。**
