## 口径校准(headline:单卡 bs32 vs DDP bs16×2)

同一 K=35、同一 slice [0:5]、同一代码/超参/步数,仅并行口径不同:

| 口径 | K | 像素 L1 | `full_norm_l1` | 与 k35c 的差 |
|---|---|---|---|---|
| **k35c 单卡 bs32**(本 run) | 35 | **14.1470** | **0.246021** | 基准 |
| 历史 BPTT **2 卡 DDP bs16×2**(计划 §0 锚点) | 35 | **18.05** | **0.314064** | DDP 高 **+3.9030 px** |
| detach 时代 blockdiag(计划 §0 锚点) | 35 | 19.02 | — | 高 **+4.8730 px** |

**口径差(offset)定量:**

- 像素 L1:**+3.9030 px**。以 DDP 为基准即 **21.62%**(18.05 − 14.1470 = 3.9030);以单卡为基准为 **+27.59%**。
  等价地 单卡 = DDP × **0.7838**,或 DDP/单卡 = **1.2759**。
- 归一化:`full_norm_l1` 差 **+0.0680427**(0.314064 − 0.246021),相对 DDP 为 **21.67%** —— 两个独立质量口径给出的
  相对口径差高度一致(21.62% vs 21.67%)。
- vs detach blockdiag K=35(19.02):单卡低 **4.8730 px(−25.62%)**。

**动态形态对比(说明 offset 主要是"水平位移"而非"精炼动力学改变"):**
历史 DDP K=35 的 per-step 为 **18.27 → 18.05**(落差 0.22 px,≈1.2%,计划 §0);k35c 为
**14.3941 → 14.1470**(落差 0.2471 px,1.717%)。**绝对落差几乎相同(0.22 vs 0.247 px)**,而绝对水平差 3.90 px ⇒
口径差基本是一个近乎恒定的整体位移,BPTT 带来的"后步改善"幅度未被单卡/DDP 显著改变(相对百分比不同是因为分母不同)。

### 该 offset 能否解释"单卡 K=99/K=120 反超 DDP K=576 锚点"?

DDP K=576 锚点 = **16.42 px**。原始(raw)差距:

| 单卡点 | 像素 L1 | raw 优于 DDP K=576 | 加性校准后(+3.9030) | 乘性校准后(×1.2759) |
|---|---|---|---|---|
| K=99 | 12.88 | **−3.5400 px(−21.56%)** | 16.7830 ⇒ DDP 反优 **0.3630 px(2.16%)** | 16.4334 ⇒ DDP 反优 **0.0134 px(0.08%,实质持平)** |
| K=120 | 12.51 | **−3.9100 px(−23.81%)** | 16.4130 ⇒ 单卡仍优 **0.0070 px(0.04%,实质持平)** | 15.9614 ⇒ 单卡优 **0.4586 px(2.87%)** |

**结论:该 offset 基本可以完全解释这一"反转"。** 单卡 K=99/K=120 的 raw 领先幅度(3.54 / 3.91 px)与同 K 同 slice
实测的口径差(3.9030 px / 21.62%)在数值上几乎相等。经加性校准后 K=99 反被 DDP K=576 超过 2.16%、K=120 与
DDP K=576 实质打平(0.04%);经乘性校准后 K=99 打平、K=120 仍略优 2.87%。**两种校准口径下,原先"单卡压缩档
明显击败 DDP 全量 K=576"的结论都不再成立——它落在校准误差带内,不能被采信为真实的 K 缩放效应。**
同理,K=48(13.1483)/K=63(14.0587)在校准后也都劣于 DDP K=576(分别 +0.63 / +1.54 px)。

**校准的局限(必须随结论一起引用):**
1. 只有 **1 个**同条件控制点,offset 是在 K=35 测得的;**"offset 与 K 无关"是假设,不是实测**。K=99/120/576 处
   的真实 offset 未知,可能更大或更小。
2. 该 offset 把"单卡 vs DDP"与两个 K=35 run 之间任何其它差异(数据顺序/随机性、评测实现细节等)混在一起;
   n=1 无法把二者分离。
3. 尽管如此,21.6% 的幅度远大于通常的 seed 级波动量级,且其大小与方向恰好与"反转"缺口一致,
   因此**最简约的解释仍是口径差**,而非单卡压缩档的容量优势。
4. 提醒(文档债):`REPORT_ksweep_k48.md` / `k99.md` / `k120.md` 的锚点表把 18.05 标为"**单卡 bs32**",
   与计划 §0/§1/§7 矛盾(18.05 实为 2 卡 DDP bs16×2)。k35c 现已给出真正的单卡 K=35 = **14.1470**,
   汇总报告 `REPORT_ksweep_bptt.md` 应统一更正为 DDP 口径并采用该 offset。

## 观察

1. **k35c 落在 K=48 与 K=24 之间,并使 K=24 → K=35 → K=48 区间严格单调。** 单卡像素 L1:
   K=48 13.1483 → **K=35 14.1470** → K=24 15.0121 → K=15 15.0247。即 K 从 24 增到 35 改善
   **0.8651 px(−5.76%)**,从 35 增到 48 再改善 **0.9987 px(−7.06%)**,**方向一致、幅度同量级**,
   回答"K=48 13.15 → K=35 ? → K=24 15.01 是否单调"= **是,严格单调**。归一化(0.260945 → 0.246021 → 0.228721)
   与 `eval_recon`(0.2610 → 0.2461 → 0.2288)同样单调。**k35c 补上的这个中间点是本次 K-sweep 里最干净的单调性证据。**
2. **K=63 的离群性被进一步确认(K=48 比 K=63 好,而 K=63 又几乎与 K=35 持平)。** 新排序中
   K=63(14.0587)只比 K=35(**14.1470**)好 **0.0883 px(0.63%)**,却比 K=48(13.1483)差 **0.9104 px(+6.92%)**;
   在 K 轴上 35→48→63 应为单调改善,实际是 14.1470 → 13.1483 → 14.0587,**K=63 处明显折返**。
   k35c 使该折返的两侧锚点(K=48、K=35)都成立,因此**强化**"K=63 是真实离群点"的解释。
3. **最小值位置随 K 严格单调后移,k35c 恰好补齐序列中间的空档。** 最小步位置:
   **K=15 第 2 步 → K=24 第 3 步 → K=35 第 4 步 → K=48 第 5 步 → K=63 第 5 步 → K=99 第 7 步 → K=120 第 7 步**;
   折算为"距末步":K=15/24/35/48/99 均为倒数第 2 步,K=63/K=120 为倒数第 3 步。k35c(5 步中第 4 步最小)
   严格落在 K=24(4 步中第 3 步)与 K=48(6 步中第 5 步)之间,**与低 K 端"最小点=倒数第 2 步、末步回吐"
   的形态完全一致**,是该形态的又一独立复现。
4. **落差比例** K=15 0.249% → K=24 0.569% → **K=35 1.717%** → K=63 1.143% → K=99 6.75% → K=48 7.89% → K=120 9.68%。
   k35c 的 1.717% 高于 K=24/K=63、低于 K=48 ⇒ **落差比例本身不随 K 单调**(K=63 再度离群,与观察 2 同源),
   但 k35c 的加入使"落差随 K 增大而总体增强"的趋势在 K≤48 段更连续(K=24 0.569% → K=35 1.717% → K=48 7.89%,
   注意 35→48 是 4.6 倍跃升,非渐变)。
5. **校准支持还是推翻"单卡反超 DDP K=576"?——推翻(至少使其在校准误差内不成立)。** 详见上文口径校准节:
   实测 offset 3.9030 px / 21.62% 与 K=99(3.54 px)/K=120(3.91 px)的 raw 领先幅度几乎相等;校准后
   K=99 打平或反被超过、K=120 打平或仅微弱领先。因此**不能**再用"单卡 K=99/K=120 < DDP K=576"支持
   "压缩档容量足够好"的结论。**可以确定性陈述的是:同一单卡同代码口径内,K=120/K=99/K=48 优于 K=35,
   K=35 优于 K=24/K=15。**
