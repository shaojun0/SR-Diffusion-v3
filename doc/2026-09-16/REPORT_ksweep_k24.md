## 观察

1. **K=24 与 K=15 实际同档,低 K 端绝对质量在 K=15→24 之间几乎不改善。** 三个独立口径
   (`full_norm_l1`=0.260945、像素 L1=15.0121、`eval_recon`=0.2610)一致显示 K=24 仅比 K=15 好
   **0.08%**(0.0126 px),而 K=24→48 一口气改善 **14.2%**(1.86 px)。也就是说,slice [0:3]→[0:4]
   这多出的第 4 个解码步、多出的 9 个特殊 token,**在这个区间几乎买不到质量**;真正的容量阈值落在
   K≈24 与 K≈48 之间。单卡六点由差到好:K=15 0.261159 → **K=24 0.260945** → K=63 0.244483 →
   K=48 0.228721 → K=99 0.224071 → K=120 0.217494。
2. **per-step 落差比例是全部 7 个测点中第二弱的(−0.569%),与"低 K 端精炼空间被压缩"一致。**
   4 步内 step1→last 仅 0.0858 px;全部测点落差占比序列:
   **K=15 0.249% → K=24 0.569% → K=63 1.14% → K=35 ~1.2% → K=99 6.75% → K=48 7.89% → K=120 9.68%**。
   K=24 比 K=15 高约 2.3 倍,但仍比 K=63 低约 2 倍、比 K≥48 各档低一个数量级。
   ⇒ "额外解码步的边际价值"随 K 从 15→24 略有恢复,但在 K=24 处仍处于近乎饱和区。
3. **最小值位置随 K 单调后移,是本档最有信息量的形态证据。** 最小步位置序列:
   **K=15 第 2 步 → K=24 第 3 步 → K=48/K=63 第 5 步 → K=99/K=120 第 7 步**;
   本档曲线 15.0980 → 15.0180 → **15.0037(最小)** → 15.0121(回升 +0.0085)。
   即 K 越小,精炼越早饱和、末步越容易回吐。K=24 严格落在 K=15(步 2)与 K=48(步 5)之间,
   与该趋势单调一致。回升幅度 +0.0085 px 远小于 `step_pixel_std_255`(5.49),数值上不显著,
   但"达最小后末步回升"在低 K 端(K=15/K=24)连续出现,按固定形态记录。
4. **K=24 强化、而非削弱 K=63 非单调异常。** 加入 K=24 后,单卡曲线在 K≤48 区间依旧是
   **严格单调改善**的(K=15 0.261159 → K=24 0.260945 → K=48 0.228721),K=63(0.244483)反而是
   唯一一处"更大 K 更差"的折返。因此 K=24 这个新点让"K=63 是真实离群点"的解释更可信,
   而不是把整条曲线解释为普遍非单调。**注意 K=24 的收益极小(0.08%),所以它提供的单调性证据
   强度有限,只能说"不矛盾",不能说"已证实"。**
5. **首步基座出现轻微非单调:K=24 的 step1(15.0980)比 K=15 的 step1(15.0622)差 0.0358 px。**
   即 K=24 的"零精炼"首步预测反而更差,最终反超完全来自多出的精炼步。这与"特殊 token 容量
   决定首步质量"的既有结论方向相反(容量更大却首步更差),量级 0.036 px 相对 std 5.49 很小,
   严格记录、不下定论。同时 K=24 的 step1 是单卡六点中最高的(K=48 14.2742 / K=63 14.2213 /
   K=99 13.8130 / K=120 13.8500),与 K=15 同处"低 K 首步基座最差"的一端。
6. **绝对质量仍显著优于 detach 基线,但跨口径锚点须谨慎。** K=24 比 detach 时代 blockdiag K=35
   (19.02)低 **21.1%**,比 K=35 BPTT DDP 锚点(18.05)低 **16.8%**,甚至比 K=576 BPTT DDP 锚点
   (16.42)低 **8.6%**。后两者是 2 卡 DDP bs16×2 旧口径,与"K 越大绝对质量越好"的先验相反,
   **在校准单卡↔DDP 口径差(待 `k35c`)之前不能采信**;可以确定的只是:K=24 在**同单卡同代码口径内**
   仅优于 K=15、劣于 K=48/63/99/120。
7. **异常/可疑点(严格记录,不下定论):**
   - 末步回升(观察 3):+0.0085 px,数值上在噪声量级,但形态与 K=15 一致。
   - 首步非单调(观察 5):+0.0358 px,同样在噪声量级。
   - `head_mean` 与 `tail_mean` 完全相同(15.032948),且恰等于四步 `step_pixel_l1_255` 的算术均值,
     与 K=15 报告同样现象一致,判定为统计脚本对同一数组的重复输出,非异常。
   - 无 NaN / 发散 / OOM;`TRAIN_RC=0`、`INFER_RC=0`,`k24.done` 已落盘。
8. **缺项说明**:`infer_test.json` 未包含 per-step 归一化空间 L1(只有 `step_pixel_l1_255` /
   `step_pixel_std_255`),故本文 per-step 只报 0–255 空间;`full_norm_l1` 仅有总量。
   请求的其余指标(`num_specials`、`decoder_steps`、`n`、`time_s`、`full_pixel_std_255`)均已取得,无缺失。

---

**一句话结论**:K=24(15.0121 px,norm 0.260945)与 K=15 实际同档(仅好 0.08%),远差于 K=48(13.1483);
它在低 K 端补上一个单调点、并把最小步位置推到第 3 步(滞后于 K=15 的第 2 步、提前于 K=48 的第 5 步),
因此**强化**而非削弱 K=63 非单调离群的解释,但因其自身增益极小,证据强度有限。
